# 詳解xs Book Project

このディレクトリは、Vivliostyle を使って『詳解xs』を組版するための書籍プロジェクトです。

## 使い方

```sh
cd documentation/xs/book
npm install
npm run preview
npm run build
```

## 目標

- Web エンジニア向けに `xs` と組み込み JavaScript の原理を説明する
- `xs` 固有の設計と一般的な JS エンジンの仕組みを明確に分ける
- 図表、コード、実装ソースへの読書ガイドを含める

## 収録方針

- 本文は「です、ます調」に統一します
- 図は SVG を優先します
- 既存のスクリーンショットは原則として再利用し、人手でしか取れないものは TODO として明示します
